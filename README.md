Clevo Fan Control Indicator for Ubuntu — Rust port
=================================================

Rust-переписывание [clevo-indicator](https://github.com/SkyLandTW/clevo-indicator):
индикатор в трее Ubuntu для управления вентиляторами ноутбуков Clevo через
Embedded Controller (EC).

Программа показывает температуру CPU на значке индикатора, отражает скорость
вентилятора иконкой и позволяет переключаться между автоматическим и ручным
режимом через меню.

Реализация максимально повторяет поведение C-версии:

* отдельный процесс-воркер для доступа к EC (работает от root);
* UI-процесс работает от имени desktop-пользователя;
* обмен состоянием через `mmap(MAP_SHARED | MAP_ANONYMOUS)`;
* тот же агрессивный алгоритм авто-регулировки (держим температуру ниже ~60 °C);
* поддержка двух вентиляторов (Clevo NH55RDQ и подобные);
* GTK3 + libappindicator, те же иконки `brasero-disc-XX` и текстовый label.

Зависимости
-----------

Ubuntu/Debian:

```shell
sudo apt-get install build-essential pkg-config libgtk-3-dev libappindicator3-dev
```

Сборка
------

```shell
cargo build --release
```

Бинарник появится в `target/release/clevo-indicator-rs`.

Установка (setuid-root)
-----------------------

Программа должна иметь setuid-бит root, но запускаться из-под обычного
пользователя: root не может показывать индикатор в трее, а обычный
пользователь не имеет доступа к I/O-портам EC.

```shell
sudo install -m 4750 -g adm target/release/clevo-indicator-rs /usr/local/bin/
```

или:

```shell
make install
```

Удалить установленный бинарник:

```shell
make uninstall
```

`make clean` удаляет только артефакты сборки (`target/`), установленный
бинарник он не трогает.

> **Сосуществование с C-версией.** Rust-версия ставится как
> `/usr/local/bin/clevo-indicator-rs` и не перезаписывает установленную
> C-версию `/usr/local/bin/clevo-indicator`. При этом запустить их
> одновременно всё равно нельзя: Linux обрезает имя процесса
> (`/proc/<pid>/comm`) до 15 байт, поэтому `clevo-indicator-rs` виден как
> `clevo-indicator`. Обе версии используют эту общую проверку и откажутся
> работать вместе, что защищает EC от параллельных команд. Не переименовывайте
> бинарник во что-то, не начинающееся с `clevo-indicator`, — это сломает
> взаимную блокировку.

Использование
-------------

```shell
clevo-indicator-rs            # индикатор в трее
clevo-indicator-rs -?         # справка
clevo-indicator-rs 60         # вручную выставить 60 % (0..100)
```

Без `DISPLAY` (например, по SSH) программа просто выводит показания датчиков:

```
Dump fan information
  FAN Duty: 0%
  FA2 Duty: 0%
  FAN RPMs: 0 RPM
  FA2 RPMs: 0 RPM
  CPU Temp: 45°C
  GPU Temp: 40°C
```

Предупреждения
--------------

* Не используйте другие программы, которые обращаются к EC через `inb`/`outb`,
  одновременно с этим индикатором.
* Не убивайте процесс через `kill -9` без крайней необходимости: программа
  перехватывает остальные сигналы, чтобы не прервать последовательность команд
  EC на середине.
* Изменение оборотов вступает в силу через 1–2 секунды.

Структура проекта
-----------------

| Файл | Назначение |
| --- | --- |
| `src/main.rs` | разбор аргументов, проверка копий, `fork`, сигналы |
| `src/ec.rs` | низкоуровневый доступ к EC, запись duty, авто-кривая |
| `src/shared.rs` | общая память между процессами (атомарные поля) |
| `src/worker.rs` | процесс-воркер: чтение debugfs, запись вентиляторов |
| `src/ui.rs` | GTK3 + libappindicator индикатор и меню |
